# Backend Dependency Management

Last updated: 2026-05-13

This backend uses `requirements.txt` for input dependencies and a pinned `requirements.lock` for reproducible installs. The backend embeds the Python agent package from `../agent/src`, so local commands that import `app.main` should include that path in `PYTHONPATH`.

## Recommended (uv)

```sh
cd packages/backend
uv venv .venv
source .venv/bin/activate
uv pip sync requirements.lock
```

### Update lockfile

```sh
cd packages/backend
uv pip compile requirements.txt -o requirements.lock
```

## Notes

- Use a virtual environment to avoid system-level conflicts.
- `requirements.lock` is generated by `uv` and should be committed.
- Run backend tests with the agent path available:

```sh
cd packages/backend
PYTHONPATH=.:../agent/src python -m pytest -q
```

- Start the dev server the same way:

```sh
cd packages/backend
PYTHONPATH=.:../agent/src python -m uvicorn app.main:app --reload
```
